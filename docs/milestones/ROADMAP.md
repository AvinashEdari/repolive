# Roadmap

1. Foundation and validation.
2. Bounded GitHub ingestion and deterministic analyzers.
3. Real results UI and explainable scoring. (Implemented)
4. Persistence, quotas, sharing, and Supabase authentication. (Implemented and staging verified)
5. Security, abuse protection, privacy, and production hardening. (Implemented and staging verified)
6. CI/CD, observability, SEO, legal pages, and operations. (Implemented; legal review pending)
7. High-value product expansion: deterministic pasted-error diagnosis, cached repository
   comparison, bounded explainable GitHub discovery, and a privacy-preserving local-agent protocol
   design. (Implemented; local agent remains intentionally unbuilt)
8. Future production-launch work: distributed abuse controls, retention automation, monitoring
   provider selection, professional legal review, and isolated-execution research.
